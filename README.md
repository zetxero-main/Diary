# บันทึกของฉัน

เว็บบันทึกส่วนตัวที่เปิดให้ทุกคนอ่านได้ เขียนจากมือถือได้ ฟรีทั้งหมด

- เว็บ: https://zetxero-main.github.io/Diary/
- หน้าเขียนบันทึก: https://zetxero-main.github.io/Diary/admin/

---

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)

### 1. ตั้ง `main` เป็น branch หลัก (default branch)

GitHub Pages เผยแพร่เว็บจาก **default branch เท่านั้น** ถ้า default ยังเป็น branch อื่น เว็บจะไม่ขึ้น (หรือสร้างเว็บแล้วเผยแพร่ไม่ได้) จึงต้องทำขั้นนี้ก่อนเปิด Pages

1. เข้า https://github.com/saharatyokthuan/Diary/settings (แท็บ **Settings** → **General**)
2. เลื่อนลงไปที่หัวข้อ **Default branch** แล้วกดปุ่มลูกศรสองทาง ⇄ (Switch to another branch)
3. เลือก `main` → กด **Update** → กดยืนยัน **I understand, update the default branch**

### 2. เปิด GitHub Pages

1. เข้า https://github.com/zetxero-main/Diary/settings/pages
2. ช่อง **Source** เลือก **GitHub Actions**
3. รอประมาณ 1–2 นาที แล้วเปิด https://zetxero-main.github.io/Diary/ ดู

> เว็บจะอัปเดตเองทุกครั้งที่มีการเปลี่ยนแปลงใน branch `main`

### 3. สร้างรหัสสำหรับเข้าหน้าเขียน (Personal Access Token)

หน้าเขียนบันทึกใช้รหัสนี้แทนรหัสผ่าน และมีแค่คุณที่มีรหัสนี้ จึงไม่มีใครอื่นแก้เว็บได้

1. เข้า https://github.com/settings/personal-access-tokens/new
2. **Token name:** ตั้งชื่ออะไรก็ได้ เช่น `เขียนบันทึก`
3. **Expiration:** เลือกอายุ เช่น 1 ปี (เมื่อหมดอายุให้สร้างใหม่ตามขั้นตอนเดิม)
4. **Repository access:** เลือก **Only select repositories** แล้วเลือก `Diary`
5. **Permissions → Repository permissions → Contents:** เลือก **Read and write**
6. กด **Generate token** แล้ว **คัดลอกรหัสเก็บไว้** (GitHub จะแสดงให้เห็นครั้งเดียว)

> อย่าส่งรหัสนี้ให้ใคร ถ้าคิดว่ารหัสหลุด ให้กดลบที่ https://github.com/settings/personal-access-tokens แล้วสร้างใหม่

### 4. เข้าหน้าเขียนบนมือถือ

1. เปิด https://zetxero-main.github.io/Diary/admin/ ในเบราว์เซอร์มือถือ (Chrome หรือ Samsung Internet)
2. กด **Sign In Using Access Token** แล้ววางรหัสจากขั้นที่ 3
3. เบราว์เซอร์จะจำไว้ ครั้งต่อไปไม่ต้องใส่อีก
4. แนะนำ: กดเมนู ⋮ → **เพิ่มลงในหน้าจอหลัก** จะได้ไอคอนเปิดหน้าเขียนได้ทันที

## เขียนบันทึกใหม่ (คัดลอกจาก Samsung Notes)

1. เปิดบันทึกใน **Samsung Notes** → กดค้างที่ข้อความ → **เลือกทั้งหมด** → **คัดลอก**
2. เปิดหน้าเขียน → **บันทึก** → **New**
3. ใส่ **ชื่อเรื่อง** (**วันที่** จะใส่วัน-เวลาปัจจุบันให้เอง ถ้าต้องการวันอื่นแก้ได้)
4. **หมวดหมู่:** ช่องละ 1 หมวด พิมพ์ชื่อหมวดในช่อง เช่น `อาหาร` แล้วกดปุ่ม **Add หมวดหมู่** เพื่อเพิ่มช่องสำหรับหมวดถัดไป (มีหลายหมวดก็ทำซ้ำ อย่าพิมพ์หลายหมวดรวมในช่องเดียว หรือคั่นด้วย `,`) ถ้าพิมพ์หมวดใหม่ เว็บจะสร้างหน้าหมวดนั้นให้เอง
   **ใช้ชื่อหมวดเดิมให้สะกดเหมือนเดิม** เพราะถ้าสะกดต่างไปแม้นิดเดียว จะกลายเป็นหมวดใหม่
5. **รูปปก** (ไม่บังคับ): กดเลือกรูปจากแกลเลอรี
6. **เนื้อหา:** วางข้อความที่คัดลอกมา แทรกรูปเพิ่มได้ด้วยปุ่มรูปภาพในแถบเครื่องมือ
7. กด **Save** (บันทึก) → รอประมาณ **1–2 นาที** แล้วบันทึกจะขึ้นบนเว็บ

> รูปจากมือถือจะถูกย่อขนาดอัตโนมัติก่อนอัปโหลด ไม่ต้องย่อเอง
>
> ถ้ายังเขียนไม่เสร็จ ให้เปิด **ฉบับร่าง** ไว้ก่อน บันทึกจะยังไม่แสดงบนเว็บ พอเขียนเสร็จค่อยปิดแล้วกด Save อีกครั้ง
>
> **ระวัง:** ที่เก็บงาน (repo) นี้เป็นแบบสาธารณะ ฉบับร่างแค่ไม่แสดงบนหน้าเว็บ แต่ใครก็เปิดอ่านได้บน GitHub จึงอย่าเขียนเรื่องส่วนตัวหรือความลับไว้ในฉบับร่าง

### แก้ไขหรือลบบันทึก

เปิดหน้าเขียน → **บันทึก** → กดบันทึกที่ต้องการ → แก้แล้วกด **Save** หรือกดเมนูเพื่อ **Delete**

---

## ถ้าบันทึกไม่ขึ้นเว็บ

1. รอประมาณ **5 นาที** แล้วรีเฟรชหน้าเว็บอีกครั้ง (ทุกครั้งที่กด Save เว็บต้องสร้างใหม่ ใช้เวลาสักพัก)
2. เปิด https://github.com/saharatyokthuan/Diary/actions แล้วดูรายการบนสุด
   - วงกลมสีเหลืองหมุน ๆ = กำลังสร้างเว็บ รอต่อ
   - เครื่องหมายถูกสีเขียว = สำเร็จ
   - **เครื่องหมาย ✗ สีแดง = สร้างเว็บไม่สำเร็จ** เว็บจะยังเป็นเวอร์ชันก่อนหน้าไปก่อน
3. ถ้าเป็น ✗ สีแดง สาเหตุที่น่าจะเป็นที่สุดคือ**บันทึกล่าสุดที่เพิ่งแก้หรือเพิ่งเขียน** ให้เปิดบันทึกนั้นในหน้าเขียน (`/admin/`) แล้วตรวจ **ชื่อเรื่อง**, **วันที่** และ **หมวดหมู่** (ต้องมีอย่างน้อย 1 หมวด) ให้ครบ แล้วกด **Save** อีกครั้ง
4. ถ้ายังไม่หาย กดที่รายการสีแดงนั้น คัดลอกข้อความ error ที่เห็น แล้วส่งให้ผู้ช่วยหรือคนที่ดูแลเว็บช่วยดู

## เปลี่ยนชื่อเว็บและหน้าเกี่ยวกับ

- **หน้าเกี่ยวกับ:** หน้าเขียน → **หน้าเว็บ** → **เกี่ยวกับฉัน**
- **ชื่อเว็บ:** แก้ไฟล์ `src/site.config.ts` บน GitHub (เปิดไฟล์ → กดรูปดินสอ ✏️ → แก้ `title` → **Commit changes**)

---

## สำหรับนักพัฒนา

```bash
npm install
npm run dev        # เปิดเว็บในเครื่องที่ http://localhost:4321/Diary/
npm test           # ทดสอบ logic
npm run test:e2e   # ทดสอบหน้าเว็บที่ความกว้างมือถือ
```

- สร้างด้วย [Astro](https://astro.build) — บันทึกอยู่ที่ `src/content/notes/`, รูปอยู่ที่ `src/assets/notes/`
- การทดสอบหน้าเว็บใช้บันทึกทดสอบใน `tests/fixtures/notes/` (ตั้งผ่าน `NOTES_DIR` ใน `playwright.config.ts`) ไม่ได้ใช้บันทึกจริง จึงลบหรือแก้บันทึกบนเว็บได้โดยไม่ทำให้การทดสอบพัง
- หน้าเขียนใช้ [Sveltia CMS](https://github.com/sveltia/sveltia-cms) — ตั้งค่าที่ `public/admin/config.yml`
- เผยแพร่ผ่าน GitHub Actions (`.github/workflows/deploy.yml`)

## เปลี่ยนสีและฟอนต์ (แก้เองใน Acode)

สีและฟอนต์ทั้งหมดอยู่ในไฟล์เดียว: **`public/theme.css`** (มีคอมเมนต์บอกว่าแต่ละบรรทัดคืออะไร)

1. เปิด `public/theme.css` ใน Acode แล้วแก้รหัสสี (เช่น `--accent: #b4532a;`) หรือชื่อฟอนต์
2. เปิด **`theme-preview.html`** แล้วกด ▶ (Preview) เพื่อดูผลทันที กดปุ่ม สว่าง / มืด ด้านบนเพื่อดูทั้งสองโหมด
3. พอใจแล้ว push ขึ้น `main` → รอ 1–2 นาที เว็บจริงจะเปลี่ยนตาม

> `theme-preview.html` ใช้ดูในเครื่องเท่านั้น ไม่ขึ้นเว็บจริง ส่วนการจัดวางหน้า (เลย์เอาต์) ยังอยู่ในไฟล์ `.astro` ใน `src/`
